# 모행 Frontend (모두의 모든 행사)

> AI 기반 행사 검수 기능을 활용한 통합 이벤트 관리 플랫폼 프론트엔드

사용자와 관리자가 서비스를 이용할 수 있도록 React 기반 사용자 인터페이스를 구현하였습니다.

---

## 핵심 기여

- 총 23개 REST API 연동
- 관리자 검수 페이지 구현
- 신고 관리 및 신고 상세 팝업 구현
- 리뷰 목록 및 내 리뷰 상단 고정 UI 구현
- 관심행사 관리 화면 구현
- 알림 드롭다운 및 뱃지 UI 구현
- JWT 기반 인증 흐름 적용

---

## 프로젝트 소개

모행(MOHAENG)은 지역 기반 행사 정보를 공유하고 참여할 수 있는 플랫폼입니다.

본 저장소는 React 기반 프론트엔드로 사용자 화면과 관리자 화면을 담당합니다.

---

## 트러블 슈팅

### JWT 인증 처리 개선

#### 문제

초기 구현에서는 인증이 필요한 API 호출 시 토큰 처리 방식이 일관되지 않아 유지보수가 어려웠습니다.

#### 해결

공통 Axios 설정을 활용하여 인증 관련 로직을 통합하고 API 요청 구조를 개선하였습니다.

#### 결과

- 인증 로직 일관성 확보
- 유지보수성 향상
- API 호출 코드 간소화

---

## 프로젝트 회고

AI 검수 기능이 프로젝트 진행 중 추가되면서 기존 화면 구조를 수정해야 했습니다.

행사 등록 시 검수 대기 상태를 사용자에게 안내하는 UI를 추가하고, 관리자 검수 페이지를 신규 개발하였습니다.

이를 통해 기능 구현뿐 아니라 사용자 경험과 서비스 흐름을 고려한 화면 설계의 중요성을 경험할 수 있었습니다.

또한 백엔드 API와 연동하면서 데이터 흐름과 상태 관리에 대한 이해를 높일 수 있었습니다.
